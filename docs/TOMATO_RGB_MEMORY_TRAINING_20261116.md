# 旧100条局部RGB＋历史Memory：实际训练结果

本轮训练目标是旧七位置任务，不使用新的119条五阶段数据；B0默认不变。

## 提示词与监督是怎样给的

- 本Agent没有语言Prompt编码器。输入为冻结V-JEPA2视觉特征、16×58实测位置、ROI几何及过去窗口。四类名称仅是输出Schema。
- 人工Subtask给出当前类别y(t)及未来1.5s类别y(t+45帧)，尾部未来不可见标签掩码；没有把未来画面、人工真实七位置、真实转换剩余时间、操作结果或Action Chunk作为输入。
- pickup=右手拿起；harvest=右手持串左手摘取；return=放回右盘；adjust沿用旧数据盘上调整定义。两次重复类别由原七阶段Current0.8/K2顺序逻辑处理，不是训练七类概率。
- OpenPI的阶段英文指令、Prompt版本、RTC和机器人端均未修改，无需重标Subtask。

## 数据、ROI与缓存

- 冻结100条：84训练、8开发、8历史测试。仅为84+8准备新局部缓存；不提取历史测试8条或用其调参。
- 官方V-JEPA2编码器冻结；复用三路全图3072D及实测状态缓存，仅额外编码π₀.₅实际使用的r11 interaction224视频，按Agent编码器要求resize256；不重算ROI。
- 本轮采用旧100条r11左右手交互ROI，不采用新119条取景规则，不调用新的右手锚定选择器。复用的三路源视频逐条按原SHA核对，局部视频和坐标独立锁定SHA。
- 状态归一化仅拟合84训练；ROI坐标沿用r11离线前后帧修补，历史索引因果但ROI生成非因果。本结果仅作同源离线对照，不宣称在线因果性能；线上输入验收未完成。
- 共25728个完整16帧/10Hz窗口；窗口内ROI有效比例加权约100.000%。这是算法有效性，不是独立语义正确率。
- 历史8个2Hz窗口端点覆盖3.5s，最早原始帧覆盖5s；早期不足8份用显式padding mask，跨Episode与>0.75s缺口重置，禁止重复首窗口伪造历史。
- 完整视觉窗口需1.5s才能形成；所有方法包括B0用同一anchor≥45起点比较。首阶段均长于1.5s。旧全时间轴B0指标保留，不能混用两种起点的分类分数和每分钟误报。

## 单因素对照

- G0：相同四通道容量，但第四路和ROI几何置零，仅最新完整窗口。
- G1：真实局部图及ROI几何/有效性，仅最新窗口。G0→G1比较局部观测包的增益，不能把RGB与几何贡献完全分开。
- G2：与G1相同模型、同样输入，读最近8个因果窗口。G1→G2才是本轮历史增量对照。
- 相同128维注意力读出、三种子42/43/44逐位相同初始化、相同随机批次、30epochs/batch128、AdamW LR0.0003/WD0.01，Current/Future损失1:1。训练独占归一化与类别权重，固定最后epoch，不以开发结果搜索epoch或阈值。
- 原B0独立双头没有重新训练。G0相对B0还改变读出结构、训练84条和标注版本；只有匹配G0/G1/G2差异可作单因素归因。

- G1_local_current_minus_G0_global_current：按时切换差+4.167个百分点，95%录制配对区间[0.6944444444444443, 9.027777777777775]。

现有8条开发录制已经反复探索，以上区间不能证明未知录制泛化。不挑选最好种子，不依据历史测试选择模型。

## 本轮结论与全参数微调可行性

- G2相对冻结B0：Current F1差-0.00200、Future F1差-0.00659；三种子状态不一致合计119.5→107.5s。
- G2严格预警命中89/144，B0为106/144；未匹配预警46→71。状态时间局部改善不等于整体决策改善。
- G0/G1/G2是同结构同预算的配对对照；G0相对原B0同时改变读出结构、训练数据版本和联合损失，不能将G0较弱归因于编码器表征不足。
- 不晋级新模型，不替换B0。保存全部九个新权重作离线研究；未来辅助ROI坐标未经在线输入一致性验收，不启用真实控制。

V-JEPA2编码器可以做全参数微调，不是只能训练读出。以下为真实四路视频的单步反向/AdamW资源探测；不代表正式全量收敛、训练吞吐或性能增益。
- 历史1窗口：303885312个编码器参数获得梯度，峰值分配4.66GiB，单次更新0.518s；未保存或覆盖编码器权重。
- 历史8窗口：303885312个编码器参数获得梯度，峰值分配7.87GiB，单次更新2.535s；未保存或覆盖编码器权重。
- 全量微调需要重新做视频前向/反向，不能继续将冻结特征缓存当作可学习编码器输入。先保留本轮匹配对照；后续全量实验应锁定数据、预算和验证规则，不假定必然提升。
