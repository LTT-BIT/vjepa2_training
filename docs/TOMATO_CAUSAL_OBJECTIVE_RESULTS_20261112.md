# 因果多时刻监督与重叠窗口一致性：匹配实验

2026-11-12；research-tomato-agent；训练起点f2c9919加本轮保存的源文件SHA。

**没有足够证据替换B0。** 新短时序模型在已暴露开发集有少量Prompt时机收益；密集监督改善分类和部分延迟，但增加一致性并未稳定改善切换。严重提前问题仍然存在。没有宣称独立泛化或实机成功率。

## 固定项与唯一变量

- 固定100条、84训练/8开发/8历史测试；锁文件b0.lock.v3.json保持不变，清单SHA为95679c2f4457701c3898e538b83883c27106aa3aa44c647ad046b92dd20410e1。
- 使用同一4000D冻结特征：三相机均值3072D及16×58位置历史928D。每个视觉缓存窗口结束于自己的观测时刻；新增上下文为最近4个2Hz观测，首末锚点相差最多1.5s。缺失历史有显式掩码，间隔超过0.6s重新开始；不跨Episode。
- 相同4000→128/GELU/Dropout0.3→单向GRUCell128→Current4。每个时刻均有因果读出；不接真实七阶段、未来观测、真实剩余时间或Episode进度。
- T0仅监督最新读出；T1最新权重1、较早有效读出权重0.25；T2再加权重0.1的对称KL，比较两个重叠上下文中**绝对时间戳相同**的读出。KL使用关闭Dropout的确定性读出，梯度流经两侧；不要求相邻不同时间戳一致。
- 所有方法相同初始化、随机批次、训练折、30epochs、batch256、AdamW LR0.0003/WD0.01、训练折归一化与类别权重。使用固定末epoch，不用开发集选epoch或阈值。
- 原B0 Current/Future模型不重训。新Current与原冻结1.5秒Future配对，2Hz、Current0.8/K2、七阶段顺序及Prompt决策代码不变；新模型只用于离线研究。
- 84条按source_recording_id做相同5折，三种子，每方法还有训练84条的最终模型：共54次小模型拟合。此处复用原始录制身份；没有宣称其为更高层采集批次的跨域划分。
- 这不同于历史Joint GRU的末帧双分类实验：本轮是Current-only的匹配损失对照，Future完全固定。T0相对B0同时改变结构、训练数据和权重，不能把两者差异归因于监督损失。

## 评价口径与数据限制

- 主Prompt按时：真实边界之后、min(边界+2s,本阶段结束)之前确认；另外报告不提前且延迟≤1.0/1.5/2.0s的共同口径。Future严格预警独立计算，不能当作Prompt成功。
- 所有旧原始标签、14项历史人工复核提案、正式标签身份和旧checkpoint保持原样。本轮沿用锁定评估有效标签；没有把提案重新宣布为正式批准修订，没有根据新模型改边界。
- 历史测试8条没有评分或用于调参。开发8条和B0未见的训练10条此前已经多轮探索，均非盲测。
- OOF84仅保证**新Current头**不见留出录制；原B0 Future见过其中74条。原B0在84条中的训练样本内分数不应与新头OOF公平排名。下面另列B0未见、也被新头留出的10条，但它们仍已暴露。
- 三种子累计计数是同一录制重复运行，不是新增独立事件。逐录制配对Bootstrap先对种子取平均再抽样录制；在已暴露数据上的区间不能代替独立泛化验证。

### 困难转换与严重错误

|方法|adjust→pickup按时/提前/滞后（24次）|提前>1s|滞后>1.5s|不提前且≤1s|
|---|---|---:|---:|---:|
|冻结B0|14/5/5|3|10|99|
|T0 末帧|15/4/5|3|8|101|
|T1 密集因果监督|15/4/5|3|6|111|
|T2 加同时间戳一致性|14/5/5|3|6|110|

- T1使开发分类F1相对T0三个种子均提高；状态不一致总时间125→112s，≤1s非提前确认101→111。但2s按时135→134，提前4→5，说明分类更准不等于边界时机全面更好。
- T2相对T1开发F1提高，但2s按时134→133，提前5→6，状态不一致112→113s。没有一致性训练改善最终切换的稳定证据。
- adjust→pickup开发按时仅由B0的14/24变成T0/T1的15/24，T2回到14/24。三组仍都有3次超过1s的严重提前，核心问题没有解决。这3次是同一条录制`3e645bf4e137d0f836c9d7ff`第4边界在三个种子的重复：B0提前2.233/2.733/3.233s，T0提前2.733/3.733/2.233s，T1提前2.233/2.733/2.233s，T2均提前2.733s；不能当作三条独立录制。
- B0未见10条中T2为162/180按时、B0为159/180，提前也从6增加到8。录制配对差值+1.67个百分点，95% Bootstrap区间约[-2.78,+6.67]；不构成稳定增益证据。
- 原Future严格预警三种子仍为37/48、34/48、35/48，未匹配预警13/18/15；本轮没有优化Future预测头，不能把Current改善说成Future召回提高。

### 一致性目标是否真的生效

|种子|T0同时间戳KL|T1|T2|
|---|---:|---:|---:|
|42|0.003798|0.000718|0.000882|
|43|0.003155|0.001165|0.001110|
|44|0.003739|0.000927|0.000742|

密集监督后，同一时间戳在不同历史中的读出已更一致；额外KL不在每个种子进一步降低KL。即使输出更一致，错误边界判断也可能更一致，所以不能用这个代理指标选部署模型。这里测试的是一个固定小规模实现和损失权重，不是否定论文或所有一致性方法。

## 结论与下一步
