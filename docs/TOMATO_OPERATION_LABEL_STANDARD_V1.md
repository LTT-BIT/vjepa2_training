# 番茄独立操作结果标签规范（含v2审核契约）

此规范是新标签任务，不等于已有pickup/harvest/return/adjust。阶段只定位候选区间；阶段边界、文件normal/C分组、关节闭合、手臂抬升都不能直接生成成功标签。初始全部未审核，Unknown也必须是实际审核后的结论；不能把未审核自动当Unknown或negative来训练。

|事件|Positive独立可见条件|Negative可见反例|Unknown|
|---|---|---|---|
|right_grasp_started|右手新的接触/闭合抓握序列可见|明确仅在移动或张手，没有新的抓握尝试|接触被遮挡、无法分清调整/抓握|
|truss_stably_lifted|番茄串离开支撑并随右手持续共同运动|右臂空抬、目标仍在盘上或明确滑落|盘面/物体遮挡，无法确认共同运动|
|left_pick_started|左手新的摘取接近/接触可见|仅返程/空手经过，明确未接近目标|目标不可见或接触关系不清|
|tomato_detached|果实从果梗分离的直接视觉证据，且后续可见状态支持|果实可见且仍连在梗上，或明显失败尝试|接触瞬间遮挡、离开画面，无法确认分离|
|truss_returned|物体受盘面稳定支撑并有释放/卸载证据|物体仍被举持，或返程但目标未落盘|放置和释放被遮挡|
|adjustment_ended|可见调整序列终止的动作锚点，并能与短暂停顿区分|明确仍在重新定位或继续调整|仅静止或手指姿态不足以确定结束|
|right_regrasp_started|新的第二次接触/闭合序列可见|仍是原调整或未开始抓握|缺少历史上下文或接触不可见|
|second_grasp_verified|新的物体-右手稳定共同运动/持有证据|空抓、滑落或目标仍在盘面|物体遮挡，不能判断是否真正持有|

“开始尝试”和“结果验证”是两类不同语义。即使两者都为positive，开始尝试不能作为结果成功的训练替代。Negative必须具备可观察条件；看不见不是negative。

帧区间为原始30Hz的[start_frame,end_frame)，不得按裁剪后视频起点写回。evidence_end_frame是作出当前结论最早所需的最后观测帧，必须位于区间内。Oracle历史只有在这个帧已到达后才释放；不能用区间开始提前释放。模型只读当前及过去的特征。标签区间应覆盖物理条件真实可判断的时间，不为凑2Hz样本随意延长。

两名审核者独立填写直接证据说明、可见相机和帧区间。每个导出保留源标注SHA和审核者身份；完全一致才由merge工具批准，分歧交人工裁决，不自动平均边界。相机角色尚无归档映射证据，先保留cam0/1/2，不擅自称其右腕/左腕。工具不展示模型分数，阶段标签仅用于后台寻找候选。

2026-11-11按用户要求从完整任务实验排除一条三阶段验证录制；当前100条清单为84训练、8验证、8历史测试。完整队列来自训练/验证92条，共736个候选；当前8770先展示训练集16条试点、128个候选，覆盖11个来源包。名单和选择规范见`configs/tomato_stage_history_20261111/pilot16.json`，原100条完整队列、101条及741候选版本保留。一个harvest候选不能代表所有摘取；当前页面不提供新增候选功能，后续必须扩充候选目录、逐次独立审核真正可见的分离事件后才可能讨论计数。当前版本不分配Tomato ID、不把阶段次数当摘取数，picked_count一直为Unknown。

打开`http://127.0.0.1:8770/`，先填名字、点“开始标注”。页面用中文直接问一件事，例如“番茄串真的被拿起来了吗？”。按三个步骤操作：①看放大的视频，必要时切换画面一/二/三；②选符合问题的肯定、否定或“看不清”；③能确定时暂停在最早能判断的位置，点“记住当前画面”，再点一句符合画面的描述或自己写一句，最后点“保存，查看下一项”。看不清时不标结果时间，只说明原因并保存。结束时点上方“导出我的标注”。帧号、区间、录制编号、额外证据相机放在默认收起的精确操作区。

开始尝试类事件的肯定回答只表示尝试可见，不表示抓握或摘取成功。界面没有自动选择结果、确认时间或证据描述；描述快捷按钮也必须由人明确点击。记住画面时保存所选相机和当前帧，必要时将原区间扩展到包含该帧，其他相机可在展开区补充。原v2导出协议和存储键保持一致，旧意见保留；再次填写相同名字可以继续，并优先打开尚未补齐v2审核的项目。两名审核者使用独立浏览器配置/机器；姓名仅用于隔离个人进度，不是身份认证，不能查看对方意见后声称独立。

v2的first_confirmable_frame必须由审核者明确填写，不默认复制候选帧。它表示仅看到该帧及以前就足以作出结果判断；Unknown为null。evidence_end_frame对可判定结果等于该帧，Unknown仅保留已审核区间末帧作为观察截止，不代表任何结果发生。原v1意见与修订历史保留，但须补充首次证据时间才能进入v2监督训练资格检查。

每项有固定Subtask参考边界，仅用于比较结果是在阶段转换前、当帧还是转换后才可观察，不据此生成成功标签。录制开始参考不算真实阶段转换。质量工具根据冻结参考帧重新计算差值，不信任表单自报的前后关系。两人结论、区间和首次证据帧不一致时保留双方原意见、差异字段和时间差，进入pending；不自动平均边界。合并的相机来源为双方并集，原始各人相机与证据说明仍保留。
