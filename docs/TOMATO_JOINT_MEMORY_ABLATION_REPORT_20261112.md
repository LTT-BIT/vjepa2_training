## 证据、局限及复现

每个 evaluations/<model>/<split> 保存完整概率、逐 Episode 分类和边界分桶、两类预警原始/稳定事件、C0/C1真实状态机回放及配对事件。classification.json 的 bucket_pooled 区分当前/未来目标、±.5/1/2秒、稳定区、短/长阶段、冷启动和重复阶段出现次数；每头另有四类 P/R/F1/support、混淆矩阵、NLL/Brier/ECE。Oracle persistence 仅是独立评分诊断，不能进入模型或状态机。

严格预警按预测 Current→Future 分歧事件开始计时：必须匹配真实相邻 from→to 且发生于边界前[-1,0)；稳定预警用第二个锚点时刻，不回填第一个时刻。过早持续告警不会在之后滑入1秒窗口时被重记成成功。这比“窗口内曾出现正确未来标签”更严格。歧义短间隔边界显式标注。

所有模型 C0 为固定 WAIT_LATE_ACK；C1 仅关闭 ACK 的诊断，不是上线推荐。90ms 是统一模拟结果延迟，不是本轮测得的模型时延。

本轮所有训练/评估复用缓存，Encoder 新提取0次。P50/P95/P99是batch1、GPU FP32、特征已驻留的读出耗时，CPU缓存更新时间另记；P1还必须加固定B0读出成本。真正在线 Encoder+Memory 总耗时和 π0.5 并发为 NOT_MEASURED，不能把缓存读出速度当端到端速度。各模型训练时长、更新步数、最佳epoch、峰值分配显存及历史容量见 models/*/manifest.json 与 summary.json。

原文件完整性：6149 个文件 SHA 复核，unchanged=True。来源身份、58个关节字段、原视频/Parquet/标注/缓存SHA、时间戳最大网格误差记录在 source_identity.json；沿用既有1e-4秒时间戳容差以兼容长序列float32量化，没有补帧或改标注。

## Memory 归因的补充限制

K1 的位置差分在多数锚点已可由单锚点原16帧关节历史导出；因此它更像显式运动表示/归纳偏置收益，尚不能归因于新增跨锚点信息。T0+同一运动摘要的后续对照尤其必要。

OOF teacher 使用每折54条训练、6条内部验证，低于固定全训练 teacher 的75条训练；严格OOF训练历史的整体Current/Future F1分别为 0.92934/0.90217。这类 teacher 质量与val/test全训练teacher的分布差异也可能限制P1，不能由本轮负面结果推出所有历史概率记忆都无用。成员、权重、归一化和输出SHA见 teacher_provenance.lock.json，质量诊断没有用于更换teacher。

验证集完整种子置信区间见 source_paired_bootstrap.json。以 K1 Future 相对 B0R 为例，seed42/43/44 的95%配对来源区间分别为 [-.01262,+.00919]、[+.00021,+.02272]、[-.00142,+.02260]；小样本不确定性明显，不作统一显著泛化结论。
