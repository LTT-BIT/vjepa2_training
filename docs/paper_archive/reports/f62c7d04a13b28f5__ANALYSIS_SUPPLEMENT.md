## 最终判断：暂不替换当前 Joint

本轮支持“部分分类收益”，没有支持“直接改善 Agent 切换”的统一结论。以下建议仅由验证集确定，历史 test 仅用于固定方案诊断。

- **T1**：三种子平均 Current/Future F1=0.95498/0.92216；相对 B0R Δ=+0.00375/+0.00527。严格原始预警 Recall=0.4383（B0R 0.5062），FP/min=1.584（B0R 1.411）；C0 窄窗命中均值 18.67（B0R 20.33），宽窗匹配中的提前≥.5s 5.33（B0R 4.00），Wrong Active 117.578s（B0R 105.522s）。
- **T2**：三种子平均 Current/Future F1=0.95768/0.92243；相对 B0R Δ=+0.00646/+0.00555。严格原始预警 Recall=0.4877（B0R 0.5062），FP/min=1.651（B0R 1.411）；C0 窄窗命中均值 20.33（B0R 20.33），宽窗匹配中的提前≥.5s 5.67（B0R 4.00），Wrong Active 94.278s（B0R 105.522s）。
- **K1**：三种子平均 Current/Future F1=0.95240/0.92343；相对 B0R Δ=+0.00117/+0.00654。严格原始预警 Recall=0.5247（B0R 0.5062），FP/min=1.398（B0R 1.411）；C0 窄窗命中均值 19.33（B0R 20.33），宽窗匹配中的提前≥.5s 5.67（B0R 4.00），Wrong Active 78.422s（B0R 105.522s）。
- **P1**：三种子平均 Current/Future F1=0.95619/0.92104；相对 B0R Δ=+0.00496/+0.00415。严格原始预警 Recall=0.4321（B0R 0.5062），FP/min=1.491（B0R 1.411）；C0 窄窗命中均值 16.00（B0R 20.33），宽窗匹配中的提前≥.5s 3.67（B0R 4.00），Wrong Active 132.722s（B0R 105.522s）。

T1/T2：classifier-improvement（部分），forecast-anticipation-improvement 未成立（整体 F1 更高但严格预警误报增加；T1 Recall 也下降）；handshake-improvement 为混合。T2 单独将错误 Active 总时长降低，但提前提交增加，不能据此上线。

K1 是唯一通过预定研究门槛的组：Future 平均 +.00654，Current +.00117，2/3 seed 的 Future 改善；但 C0 窄窗命中下降、过早提交增加。归类为 classifier-improvement / 部分 forecast-anticipation-improvement / 混合 handshake。它适合下一阶段独立验证，暂不移植进 wait-late-ack 默认模型。还缺“同构 N=1 + 相同运动摘要”对照来区分显式运动信息与额外锚点历史贡献；本轮没有临时新增这一组。

P1：历史概率需要真实 OOF 和额外 B0 读出，Current/Future 都有小幅均值提升，但未到预设 .005 门槛且严格 Recall 下降、C0 窄窗命中与错误 Active 时长更差；当前不建议为此引入教师推理和概率 Memory。E1 不进入本轮，OperationMemory 物理成功仍不可评估。

S1 的 Future F1 上升但 Current F1 下降超出 .005，且 C0 窄窗命中从23降到11；错误 Active 秒数降低并不能掩盖时机变晚。归类为决策后处理取舍，当前不采用默认 EMA。

最小后续增量建议：保留现有 Joint + WAIT_LATE_ACK；另立独立验证，仅考察实测运动摘要及其 N=1 对照，保持现有阈值。此处只建议下一轮设计，本次没有继续调参或实现额外策略。

## Memory 归因的补充限制

K1 的位置差分在多数锚点已可由单锚点原16帧关节历史导出；因此它更像显式运动表示/归纳偏置收益，尚不能归因于新增跨锚点信息。T0+同一运动摘要的后续对照尤其必要。

OOF teacher 使用每折54条训练、6条内部验证，低于固定全训练 teacher 的75条训练；严格OOF训练历史的整体Current/Future F1分别为 0.92934/0.90217。这类 teacher 质量与val/test全训练teacher的分布差异也可能限制P1，不能由本轮负面结果推出所有历史概率记忆都无用。成员、权重、归一化和输出SHA见 teacher_provenance.lock.json，质量诊断没有用于更换teacher。

验证集完整种子置信区间见 source_paired_bootstrap.json。以 K1 Future 相对 B0R 为例，seed42/43/44 的95%配对来源区间分别为 [-.01262,+.00919]、[+.00021,+.02272]、[-.00142,+.02260]；小样本不确定性明显，不作统一显著泛化结论。
