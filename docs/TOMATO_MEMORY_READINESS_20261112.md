## 集成前的具体工作

1. **先分清接入模式**：M1 Shadow可继续使用，不需要先训练视觉Reader；学习型视觉Memory需要独立训练和无Memory对照，不可直接让未训练Reader影响Prompt。
2. **观测年龄契约**：历史bridge接收≤2s，TaskMemory接受≤1s；已有1.5s迟到反例。必须明确处理“控制器确认事实”与“过期感知”，不能偷偷改变默认阈值来通过测试。
3. **中断恢复**：可输出快照和事件日志，但旧离线脚本在Episode结束落盘；未验收断电/进程崩溃后恢复，不等于数据库级持久记忆。
4. **100条身份**：旧独立Memory协议仍记录历史9条开发，不能直接将其当当前8条运行说明；新接入应使用完整100冻结锁及本轮readiness绑定。
5. **RGB特征链路**：需把ROI来源、首次可用时刻、相机、坐标、编码器、256像素预处理及模型身份统一到Agent缓存；不能拿人工离线插值框声称在线收益，也不能把OpenPI的较小预处理图放大冒充原始局部细节。
6. **命名state**：ROI候选代码接收原始116D状态；Agent和Memory要求按名称提取的16×58 position。不能按同维数或裸下标认定顺序一致。
