## 四种策略

A baseline：原Future .5/K2预警 + 原Current .8/K2有序Prompt规则。seed42七阶段轨迹与Git锁定的历史接口逐窗口完全一致，三种子预警流与保存B0完全一致。

B detect：不改变A的Prompt/预警，只报告不属于当前或允许下一类别的Current .8/K2矛盾证据。保留多假设供诊断。另有可附接任意既有状态的StateInconsistencyDetector；不使用真实阶段，不建议四分类argmax重置。

C hypotheses：宽度3的有序状态概率过滤，允许停留或沿真实观测过的下一位置前进一步。四类概率是观测似然，七位置后验来自序列过滤，不能叫七分类概率。下一阶段至少Current .5/K2才能产生路径；后验≥.8且连续2次才提交。保留完整路径证据，不按固定Episode时间转移。

D resync：在C基础上允许最多前进两个位置的受约束重同步，必须完整观测过所有中间阶段，目标另需Current .8/K2，跨adjust必须有adjust证据。无证据不跳转；多位置推荐只记一次Prompt更新，被越过的位置不虚构到达成功。所有规则预先固定，没有阈值搜索或根据结果放宽。

时间头仅保留在证据和原B2故障诊断中，未进入新策略硬门控。模块输入只有Current/Future概率、时间戳、会话/模型身份和在线维护状态；人工标签不进入任何update函数。
