# 番茄 Agent 独立录制与边界复核方案

本轮只制定方案，没有新采集录制。现有76/10/8及历史测试结果保持原样；现有验证集已反复探索，所有改善均属于开发集证据。

建议新增12条开发录制、20条封存独立测试录制，以整条原始录制/采集场次为最小分组。20条测试至少覆盖100个真实转换；事件数不足时增加整条录制，不能按结果挑选片段。先按日期、植株/果串、场景、操作者分组，再分开发和测试；同一场次、同一原录制的裁剪/重编码不得跨组。目标是跨新场次验证，而非仅防止文件重复。

| 场景 | 采集重点 | 需要的对照 |
|---|---|---|
| adjust→pickup | 调整完成后停顿、伸手接近、抓取接触三个语义时刻分开记录；第二次pickup | 正常动作与只接近后撤、只调整不采摘 |
| return→adjust | 放置、松手、调整动作衔接；手指/盘子遮挡 | 清晰可见与局部遮挡，保留至少一路可见视角 |
| pickup→harvest | 快速衔接、抓稳后长停顿、反复抓取 | 相同静态姿态下继续/暂停操作 |
| harvest→return | 剪取后停顿、失败重试、连续采摘 | 真实return与仅移动/重新定位 |
| 跨场景因素 | 快/正常/慢各档；照明、果串形态和手臂遮挡；重复操作 | 每档跨多个原始录制，不把同一操作者等同速度 |
| 困难负例 | 预计转换但未发生、回退、缺失阶段、提前终止 | 记录真实发生的序列，不强制补齐七阶段 |

每条保存三路原始视频、原始帧PTS、机器人实测位置/关节名称/真实时间戳、录制UUID、场次、操作者、果串/场景ID、同步信息、原始标注和文件SHA。目标30Hz，保留丢帧/时间间隔，不人工补帧冒充观测；动作标注不能输入在线模型。

标注规范由两位复核者先在开发录制建立：明确pickup是接近、接触还是抓稳；return是开始返程还是完成放置；adjust的开始/结束依据。对于动作重叠保留最早/最晚合理边界区间和置信度，另存共识点，不覆盖原始标注。复核模型错误时必须记录模型是否可见；独立测试优先盲标，不看模型曲线。每次修订记录原始帧、建议帧、理由、复核者和时间。现有56个事件本轮没有自动修订标签。

模型checkpoint SHA、归一化、输入Schema、2/4Hz、阈值、确认时长、七阶段适配规则、事件匹配窗和验收门槛须先锁定并签署SHA清单。测试录制可提前采集，但标注/视频与结果由保管者封存；锁定后仅运行一次主要验收。若失败，当前测试转为已暴露数据，下轮重新录制，不反复在它上面调阈值。

建议预注册验收：严格Future事件召回≥80%、误报≤1次/分钟；Current确认召回≥90%、P95延迟≤1.5秒；单独报告提前Prompt次数，不允许整体F1抵消提前误切换。时序不确定区间分析仅作预定义敏感性分析，主结果仍采用冻结点标注。按录制报告结果和聚类置信区间，并报告每类事件支持数；20条/100事件只提供初步独立证据，不能证明所有场景可靠。
