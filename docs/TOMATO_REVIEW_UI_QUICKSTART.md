# 人工复核页面：三步使用

打开 http://127.0.0.1:8768/ 。默认先看“调整 → 重新拿起”的9段视频。

1. **选片段**：下拉框显示中文动作名称。点“下一段”可继续。
2. **看动作**：播放视频，在你认为动作开始切换的地方暂停，点“标记这一刻”。界面显示的是当前短片内的秒数，无需输入帧号。拿起的开始应看新的抓握序列，不必等到物体完全离盘。
3. **记判断**：填写名字或代号，写一句看到的动作，再保存。全部看完后点“下载已保存的判断”。意见不会直接写回原标注。

分不清准确时刻，可以展开“大概范围”分别标起点/终点；认为根本没有发生这个切换，可直接选择“这段没有发生”，取消时间标记后写明依据；画面看不清则如实选择。

概率、关节曲线、原标注和技术日志收在下面的折叠栏，普通复核可以先不看。看过模型会保留曝光记录。所有已有已保存意见、案例身份和源帧映射继续保留。
